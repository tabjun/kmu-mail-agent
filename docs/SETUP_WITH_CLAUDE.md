# Claude Desktop으로 설치하기 (교수님용)

명령어를 몰라도 됩니다. Claude Desktop의 **Code** 탭에 아래 프롬프트를 붙여 넣으면 Claude가 프로그램 받기, 설치,
항상 켜지는 서비스 등록, 설정 화면 열기까지 대신해 줍니다.

> **Code 탭을 쓰세요 (Cowork 아님).** 이 설치는 PC에서 직접 명령을 실행해야 합니다(파이썬 패키지 설치, Windows 시작 시
> 자동 실행 등록, 로컬 웹 서버 실행). Code 탭은 고른 폴더에서 이런 작업을 할 수 있고, Cowork는 문서·파일 작업용이라 맞지 않습니다.

## 준비물
- Windows PC: 항상 켜 두는 연구실 PC를 권합니다.
- Claude Desktop 앱
- **`.env` 파일**: Claude API 키가 든 파일입니다. 담당 학생이 카카오톡·메일로 따로 보내 드립니다. 받은 파일은 **다운로드**(또는 '카카오톡 받은 파일') 폴더에 저장된 그대로 두세요.
  저장할 때 이름이 `env`나 `.env.txt`로 바뀌어도 괜찮습니다.
- 학교 Office 365 계정(@ms.kmu.ac.kr)

## 1. 프로그램을 둘 `schedule` 폴더 만들기 (1분)
1. 키보드에서 <kbd>Win</kbd> + <kbd>R</kbd>을 누르고 `%USERPROFILE%`를 입력한 뒤 <kbd>Enter</kbd>를 누릅니다. 내 사용자 폴더(`C:\Users\(이름)`)가 열립니다.
2. 빈 곳에서 마우스 오른쪽 버튼 → **새로 만들기 → 폴더**를 누르고 이름을 **`schedule`**로 정합니다.
   - 최종 위치: **`C:\Users\(이름)\schedule`**
   - 문서·바탕 화면 폴더는 OneDrive로 동기화될 수 있습니다. 메일 데이터와 로그인 정보가 클라우드에 올라가지 않도록 이 위치를 씁니다.

## 2. Claude Desktop에서 폴더 고르기
1. Claude Desktop을 열고 위쪽의 **Code** 탭을 누릅니다.
2. 작업 폴더를 고르는 곳에서 방금 만든 **`schedule`** 폴더를 고릅니다.

## 3. 아래 프롬프트를 그대로 붙여 넣기

```text
GitHub 저장소 https://github.com/tabjun/kmu-mail-agent 의 '메일 비서'를 이 PC에 설치해 줘.
지금 작업 폴더(schedule)가 설치 위치야.

1. 저장소를 이 폴더 안에 바로 받아 줘(하위 폴더를 따로 만들지 말고, 설치하기.bat이 이 폴더 바로 안에 오게).
   폴더가 비어 있지 않으면 임시 폴더에 받은 뒤 내용을 이 폴더로 옮겨 줘.
   git이 없으면 https://github.com/tabjun/kmu-mail-agent/archive/refs/heads/main.zip 을 내려받아 같은 방식으로 풀어 줘.
2. API 키는 내가 따로 받은 .env 파일에 있어. 다운로드 폴더(또는 문서\카카오톡 받은 파일)에 있고, 이름이 env나 .env.txt로
   바뀌었을 수 있어. 그 파일을 이 폴더로 복사해서 이름을 .env로 해 줘(설치하기.bat 옆에 오게).
   .env 안의 값은 화면에 보여주지 말고, ROOT_API_KEY와 ANTHROPIC_WORKSPACE_ID 값이 들어 있는지만 확인해 줘.
   못 찾으면 나에게 어디에 저장했는지 물어봐.
3. 받은 폴더의 CLAUDE.md를 먼저 읽고, 거기 적힌 '처음 설치' 순서를 따라 줘.
   (.env가 이미 있으니 키 입력 없이 scripts\setup_windows.ps1 -NoPrompt 로 1~6단계를 한 번에)
4. 설치가 끝나면 항상 켜지는 서비스로 등록하고, 브라우저에서 http://localhost:3000/setup 을 열어 줘.
5. 설정 마법사(계정 연결 → 기본 설정 → 저장하고 실행)를 내가 진행하는 동안 단계마다 무엇을 누르면 되는지 짧게 알려 줘.
   2단계는 꼭 '저장하고 다음'까지 눌러야 자동 메일 확인이 시작된다는 것도 알려 줘.
6. 끝나면 대시보드의 '연결 상태'가 모두 ✅인지 확인하고, ❌가 있으면 원인을 찾아 고쳐 줘.
   문제가 생기면 data\logs\activity.jsonl 과 data\logs\server.log 를 읽어서 판단해 줘.
```

## 4. 진행 중에 교수님이 직접 하실 일
- Claude가 명령 실행 허락을 물으면 **허용**을 누릅니다.
- Claude가 키 파일을 못 찾는다고 하면, 받은 `.env` 파일을 `C:\Users\(이름)\schedule` 폴더로 끌어다 놓으세요
  (`설치하기.bat`이 있는 폴더). 이름이 `env`로 보이면 `.env`로 바꿔도 되고, 그대로 두어도 메일 비서가 알아서 찾습니다.
  대시보드 맨 위에도 키 파일을 넣을 정확한 위치가 나옵니다(Win+R → 주소 붙여 넣기 → Enter → 열린 폴더에 .env 넣기).
- 설정 마법사 1단계에서 학교 메일 주소를 입력하고 **연결하기**를 누릅니다. Microsoft 로그인 창이 열리면 계정을 고르고 **수락**을 누릅니다.
  - "관리자 승인 필요"가 뜨면 학교 승인이 아직 안 된 것입니다. 정보통신처에 [요청서](admin-consent-request.md)를 보내세요.
- 2단계에서 알림 시각 등을 고르고 **저장하고 다음**, 3단계에서 **지금 실행하기**를 누릅니다.

## 설치가 끝난 뒤
- 바탕화면의 **메일 비서** 아이콘을 열면 대시보드가 나옵니다. 맨 위 **할 일**에 오늘 처리할 일이 우선순위대로 보입니다.
- 메일에서 찾은 회의·마감은 **같은 학교 계정의 Outlook 캘린더**에 들어갑니다. 매일 알림 시각에는 **'✅ 오늘 할 일'** 일정이 들어갑니다.
  휴대폰 **Microsoft Outlook** 앱(같은 계정으로 로그인)에서도 보이고 알림이 옵니다.
- 불필요한 메일은 대시보드의 **불필요한 메일 정리** 카드에서 승인하거나 거절합니다. 승인하면 지운 편지함으로 옮겨지고, 복구할 수 있습니다.
  승인할 때마다 메일 비서가 정리 기준을 스스로 배워서, **🧠 배운 규칙** 버튼에서 확인하고 지울 수 있습니다.
- 기준을 직접 바꾸고 싶으면 🧹 / 📌 / 📅 버튼(전용 도우미)을 누르고 말로 설명하면 됩니다.

## Claude 없이 설치하려면
README의 **설치 방법 1 · 클릭만으로**를 따라 하세요. ZIP을 받아 `설치하기.bat`을 더블클릭하면 됩니다.
