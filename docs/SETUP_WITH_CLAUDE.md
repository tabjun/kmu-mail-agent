# Claude Desktop으로 설치하기 (교수님용)

명령어를 몰라도 됩니다. Claude Desktop 앱의 **Code**(또는 Cowork)에서 아래 프롬프트를 그대로 붙여 넣으면,
Claude가 저장소를 받고, 설치하고, 항상 켜지는 서비스로 등록한 뒤, 설정 화면을 열어 줍니다.

## 준비물
- Windows PC(항상 켜 두는 연구실 PC 권장), Claude Desktop 앱
- 연구실 Claude API 키(`ROOT_API_KEY`)와 워크스페이스 ID. 담당 학생에게 받으세요.
- 학교 Office 365 계정(@ms.kmu.ac.kr). 학교에서 이 앱 사용을 승인받은 계정이어야 합니다.

## 붙여 넣을 프롬프트

```text
https://github.com/tabjun/kmu-mail-agent 저장소를 내 문서 폴더에 받아서 설치해 줘.
저장소의 CLAUDE.md에 적힌 '처음 설치' 순서대로 진행하고, 단계마다 무엇을 하는지 짧게 알려 줘.
API 키와 워크스페이스 ID는 내가 대화창에 줄 테니 .env에만 저장하고 다시 보여주지 마.
마지막에 항상 켜지는 서비스로 등록하고, 브라우저에서 http://localhost:3000/setup 을 열어서
설정 마법사(계정 연결 → 기본 설정 → 저장하고 실행)를 같이 진행해 줘.
끝나면 대시보드의 '연결 상태'가 모두 ✅인지 확인해 줘.
```

## 설치가 끝난 뒤
- 바탕화면의 **메일 비서** 아이콘을 열면 대시보드가 열립니다.
- 매일 아침 알림 시각에 Outlook 캘린더에 **'✅ 오늘 할 일'** 일정이 울립니다. 휴대폰 Outlook 앱(같은 계정)에서도 같은 알림이 옵니다.
- 불필요한 메일이 오면 대시보드의 **불필요한 메일 정리** 카드에서 "지워도 될까요?"를 승인하거나 거절하면 됩니다.
- 기준을 바꾸고 싶으면 대시보드의 🧹 / 📌 / 📅 버튼(전용 도우미)을 누르고 말로 설명하면 됩니다.

## 다른 방법: 웹 화면만으로
이미 설치된 PC라면 `http://localhost:3000/guide`(사용법)를 따라 하면 됩니다.
