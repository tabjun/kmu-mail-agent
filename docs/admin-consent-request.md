**요청 권한 (모두 위임된 권한, 애플리케이션 권한 없음)**

| 권한 | 용도 |
|---|---|
| `User.Read` | 로그인한 사용자 확인 |
| `Mail.ReadWrite` | 로그인한 사용자 본인의 받은편지함을 읽어 분류하고, 사용자가 승인한 불필요 메일만 지운 편지함으로 이동 |
| `Calendars.ReadWrite` | 메일에서 찾은 마감·회의 일정을 본인 캘린더에 등록 |
| `Mail.Send` | 아침 브리핑을 **본인에게만** 발송 (필요하시면 이 권한은 빼도 됩니다) |

위임된 권한이라 앱은 로그인한 사용자 본인의 메일함과 캘린더에만 접근할 수 있습니다. 다른 사용자의 데이터에는 접근할 수 없습니다.

**데이터 처리**
- 메일 본문은 우선순위 분류를 위해 Anthropic Claude API(연구실 조직 계정)로 전송됩니다. 분류 결과는 사용자 PC의 로컬 저장소에만 저장됩니다.
- 사용 대상: 지도교수님([교수님 성함], [교수님 메일])과 개발자 본인, 테스트 단계

**사용 범위 제한 요청 (선택)**
